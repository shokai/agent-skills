# 対話コンテキストのimport手順書

過去の対話コンテキストを探し、読み込む対象を提案して読み込む。

対話コンテキストはconversation-context-export skillが書き出した物で、次の2か所にある:

- `.dev/contexts/{サニタイズ済みブランチ名}.md` のローカルファイル
- PRのコメント。本文は `# {ブランチ名} 対話コンテキスト` の見出しで始まる。`{ブランチ名}` はそのPRのhead branch名で、サニタイズしない

## 手順

### 1. ブランチ名を取得する

Bashツールで以下を実行する:

```
git branch --show-current
```

### ブランチ名のサニタイズ

ブランチ名をファイル名として使う際、以下の文字を `-` に置換する:

```
/ \ : * ? " < > |
```

例: `dependabot/npm_and_yarn/feed-5.2.0` → `dependabot-npm_and_yarn-feed-5.2.0`

以降の手順では、サニタイズ後のブランチ名を「サニタイズ済みブランチ名」と呼ぶ。

### 読み込み元ディレクトリの決定

ローカルファイルの読み込み元をgit worktreeの状況に応じて決める。

Bashツールで `git worktree list` を実行し、現在の作業ツリーがmain worktree（リポジトリ本体の作業ツリー）か、リンクされたworktreeかを判断する。worktreeで作業している場合はmain worktreeのパスも把握する。

main treeで作業中の場合は、読み込み元ディレクトリを `.dev/contexts/` とする。

worktree内で作業中の場合は、main treeとworktreeローカルの両方の `.dev/contexts/` で、カレントブランチ用ファイル（`{サニタイズ済みブランチ名}.md`）の有無を確認して読み込み元ディレクトリを決める:

- 両方に存在する場合: 両方のフルパスを提示し、AskUserQuestionツールでどちらを読み込むか選ばせる。選んだ側の `.dev/contexts/` を読み込み元ディレクトリとする
- 片方のみに存在する場合: そちらの `.dev/contexts/` を読み込み元ディレクトリとする
- どちらにも存在しない場合: main treeの `.dev/contexts/` を読み込み元ディレクトリとする

以降の手順では、決定したパスを「読み込み元ディレクトリ」と呼ぶ。

### 2. 候補を集める

#### PRコメント

次のPRを探し、それぞれのコメント欄にある対話コンテキストを候補にする。mergeされたPRとcloseされたPRも探す。

- カレントブランチのPR
- その子PR
- その親PR
- 兄弟の子PR: 親PRの子PR

PR同士の親子関係は、baseと概要欄の両方で辿る。子PRのbaseは親PRのhead branchで、概要欄では親PRと子PRが互いにリンクされる。

カレントブランチのPRが未作成の時は、baseがdefault branchのopenなPRのうち、head branchにあってbase branchに無いcommitをHEADが含んでいる物を親PRとみなす。

GitHub CLIが使えないか、認証されていない時は、PRコメントを探さず、その事を報告に含める。

#### ローカルファイル

読み込み元ディレクトリのファイルのうち、カレントブランチと、見つけたPRのhead branchに当たる物を候補にする。

#### 同じbranchの重複

同じbranchの対話コンテキストが、ローカルファイルと、自分が投稿したPRコメントの両方にある時は、メタデータのUpdated atが新しい方を候補に残す。2つが食い違っていた時は、その事を報告に含める。

### 3. 読み込む対象を提案する

候補が1つだけで、それがカレントブランチの対話コンテキストなら、質問せずに読み込む。

それ以外で候補がある時は、候補の一覧を示し、読み込む対象の案を出して、AskUserQuestionツールで承認か修正を求める。

- 一覧には、候補ごとに、ファイルのパスかコメントのURL、PRの番号・タイトル・状態、カレントブランチとの関係を書く
- 案では、タイトルと概要欄から意図の理解に役立たないと判断した候補を外し、外した理由を添える。動作を変えない機械的な変換だけのPRがこれに当たる

候補が1つも無い時は、探した場所と、対話コンテキストが見つからなかった事を報告して終了する。

### 4. 読み込みと報告

対象の対話コンテキストの全文を読み込む。

読み込み完了後、どの対話コンテキストを読み込んだかをユーザーに報告する:

```
以下の対話コンテキストを読み込みました:
- `{読み込み元ディレクトリ}/feature-a.md`
- #1235 {PRのタイトル}: {コメントのURL}
```

## 関連スキル

- **conversation-context-export**: 現在の対話コンテキストを `.dev/contexts/` に書き出し、PRがあればPRコメントにも投稿するスキル。開発の区切りでコンテキストを保存する時に使用する。
