# prose-proofreading

Markdownドキュメントの文章を校正するAgent Skillです。ガイドラインに基づいて文体の問題を検出し、修正案を提示します。

## 使い方

```bash
/prose-proofreading [file-path or branch-diff]
```

作業中に「文章を校正して」「文体を直して」「ドキュメントを校正して」と伝えると発動します。

## インストール方法

マーケットプレイスを登録してから、pluginをインストールします。

```bash
/plugin marketplace add shokai/agent-skills
/plugin install prose-proofreading
```

既にマーケットプレイスを登録済みの場合、新しいスキルをインストールするには [マーケットプレイスの更新](../../README.md#スキルをうまくインストールできない場合) が必要です。

他のpluginは [リポジトリルートのREADME](../../README.md) から探せます。
